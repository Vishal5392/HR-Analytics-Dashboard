# HR Analytics Dashboard | Tableau

## Project Overview
Interactive HR Analytics dashboard built in Tableau to analyze employee attrition and identify key factors affecting employee retention.

## Live Dashboard
🔗 [View on Tableau Public](https://public.tableau.com/views/HRDataDashboard_17899168012530/HRAnalyticsDashboard?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

![Dashboard Preview](HRDataDashboard_Tableau.twbx)

## Key Metrics
- Total Employees: 1,470
- Attrition Count: 237
- Attrition Rate: 16.12%
- Active Employees: 1,233
- Average Age: 37

## Key Insights
- R&D department has the highest attrition (133 employees, 56.12%)
- Life Sciences education field has the most attrition (89)
- Male employees have higher attrition (150) than female (87)
- Attrition is highest in the 25-34 age group (112 employees)
- Sales Executive and Research Scientist roles show higher dissatisfaction

## Dashboard Features
- Department-wise attrition analysis
- Employee distribution by age group (adjustable bin size)
- Job satisfaction rating by job role
- Education field-wise attrition
- Attrition by gender across age groups
- Education filter for interactive analysis

## Tools Used
- Tableau Public
- Dataset: IBM HR Analytics Employee Attrition
